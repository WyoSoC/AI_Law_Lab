Outside the libraries optional

Whether the agents may also look beyond the libraries. Both are off unless you tick them.

{% if not web_ready %}Open-web search is not set up on this server (it needs a search key). {% endif %}A study of model reasoning shouldn't silently reach outside sources, so both start off. The legal databases are official sources with their own interfaces. The open web reaches much more (agency guidance, scholarship, foreign law, news) and its search queries go to an outside search service. Web addresses written in the brief are read before research starts.

What happens to what the agents read

  1. Reading. Agents may read any page whose site lets AI agents read it (robots.txt, “noai”, text-and-data-mining reservations); pages turned away are listed on the run page. They may use and cite what they read. This is much like a person browsing the web while researching for relevant information.
  2. Keeping a copy. A full copy is saved to the library below only when an agent judges the source reliable and useful and a rights check in the code is positive: court opinions and the other legal databases (including SEC EDGAR filings), listed US federal sites, or a page that marks an open license (Creative Commons, public domain). When the rights are unclear, no copy is kept. This behavior is consistent with the four-factor fair use test under 17 U.S.C. § 107.
  3. Citing what was not kept. The citation gives the page's address, when it was read and a fingerprint of its text; only the cited passages are stored, as quotations. The run page marks these “read online, not kept”: the page may change later.

Time limit

How long the agents may research before they must write up what they found.

minutes

Research has no limit on sources or steps: each agent reads what its sub-question needs. The time limit is the safety net: when it is reached, or when you press Stop on the run page, the agents report what they have found and the answer is written from that.
